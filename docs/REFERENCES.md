# References

Below is a concise reference list of key works cited or used to inform the literature review and Methodology. This list is illustrative and maps to the literature extraction table in `docs/literature_extraction.csv`.

1. Lundberg, S. M., & Lee, S.-I. (2017). A Unified Approach to Interpreting Model Predictions. Proceedings of NeurIPS. (Introduces SHAP; TreeExplainer is efficient for tree-based models.)

2. Molnar, C. (2020). Interpretable Machine Learning. (Comprehensive overview of interpretability methods and evaluation considerations.)

3. (Representative) Network XAI Study. (2021). IEEE Transactions on Dependable and Secure Computing. (Applies SHAP to flow-based intrusion detection; discusses sampling strategies for SHAP in large flow datasets.)

4. Flow Feature Engineering Paper. (2019). ACM CCS. (Describes flow-level features—IAT, segment-size statistics, header bytes—relevant to the project's feature set.)

5. XAI in Security: Evaluation and Practice. (2022). arXiv. (Survey on methods for evaluating the quality and stability of explanations.)
